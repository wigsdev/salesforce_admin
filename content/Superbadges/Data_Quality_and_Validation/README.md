## 🗺️ Estructura del Superbadge

El desafío se divide en las siguientes áreas clave:

| # | Área de Conocimiento | Objetivo |
| :--- | :--- | :--- |
| **1** | **Importación de Datos** | Mapear y limpiar valores de `Lead Source` desde datos legados (RAS). |
| **2** | **Gestión de Duplicados** | Configurar `Matching Rules` (Fuzzy Name) y `Duplicate Rules` para Contactos. |
| **3** | **Validación de Oportunidades** | Reglas para `Stage` cerrados, fechas pasadas y bloqueos de edición de `Amount`. |
| **4** | **Automatización (Flows)** | Flow para `Tasks` que restringe fechas de vencimiento en casos de alta prioridad. |
