## 🗺️ Estructura del Superbadge

El desafío se divide en 3 casos de uso principales para **Dreamscape Bookshops**:

| # | Caso de Uso | Tipo de Flow | Objetivo |
| :--- | :--- | :--- | :--- |
| **1** | **Book Order Giveaway** | Record-Triggered | Crear Tareas para el equipo de cumplimiento si el pedido tiene >3 libros. |
| **2** | **Recommendation Email** | Screen Flow | Permitir al equipo enviar emails personalizados desde el Contacto. |
| **3** | **Loyalty Program** | Autolaunched/Schedule | Actualizar puntos de fidelidad en el cumpleaños del cliente según su Nivel (Gold/Silver/Bronze). |

## 🛠️ Prerrequisitos

1.  Crear una **Developer Edition** especial desde [este link](https://developer.salesforce.com/promotions/orgs/superbadge-flow-fundamentals).
2.  Conectar la Org a tu perfil de Trailhead.
3.  ¡No usar una Org vieja! Los datos de "Books" y "Loyalty" son específicos de este reto.
