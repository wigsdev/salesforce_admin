# Superbadge: Multi-Factor Authentication and Single Sign-On Settings

Este directorio contiene los recursos y guías para completar el Superbadge de **Multi-Factor Authentication and Single Sign-On Settings** de Salesforce Trailhead.

## Contenido

* **[ENUNCIADO ORIGINAL.md](./ENUNCIADO%20ORIGINAL.md)**: Contiene los requisitos originales, instrucciones y casos de uso copiados directamente de Trailhead para referencia rápida.
* **[GUIA_SB_SOLUCION.md](./GUIA_SB_SOLUCION.md)**: Una guía paso a paso detallada para configurar la org, resolver los retos de SSO y MFA, y verificar la solución.

## Objetivos de Aprendizaje
* Configuración de Single Sign-On (SSO) entrante.
* Implementación de Multi-Factor Authentication (MFA).
* Activación y uso de Lightning Login.
* Uso de Salesforce Authenticator App.
