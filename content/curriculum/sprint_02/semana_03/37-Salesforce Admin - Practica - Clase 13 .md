Skills Técnicas (El "Qué" haces)
Gestión de Usuarios y Seguridad: El pan de cada día. Crear usuarios, resetear contraseñas, asignar Perfiles y Roles sin abrir brechas de seguridad.
Gestión de Datos (Data Management): Limpieza, carga masiva (Data Loader/Import Wizard) y prevención de duplicados. Saber que "datos sucios = reportes inútiles".
Automatización Básica (Flows): Capacidad de crear flujos sencillos (Record-Triggered) para reemplazar tareas manuales repetitivas.
Reportes y Dashboards: Crear visibilidad para los jefes. Saber traducir preguntas de negocio ("¿Cuánto vendimos?") en gráficos.
AgentForce: puedas familiarizarte con la configuración de agentes dentro de Salesforce.

¿Qué es una API? (Concepto Clave)
Definición simple: Es un contrato o puente que permite que dos aplicaciones diferentes se hablen entre sí.
La Analogía del Mesero:
Tú (Cliente): La app externa (ej: una web, un móvil).
La Cocina: Salesforce (Base de datos).
El Mesero: La API. Tú le pides algo al mesero (Request), él va a la cocina, y te trae la comida (Response). No entras a la cocina a cocinar tú mismo.



Los 4 Principales de API (¡Esto es examen seguro!)



El Archivo WSDL (Solo para SOAP)
Es un archivo XML que "describe" tu Org para que el otro sistema sepa qué campos existen.
Enterprise WSDL: Es específico para TU org (muy rígido, si cambias un campo, se rompe).
Partner WSDL: Es genérico (ideal para apps que sirven a múltiples clientes/orgs).



💡 Tips para los Retos (Hands-on Challenge)
En este módulo, los retos suelen ser Cuestionarios (Quizzes). Aquí están las pistas para que tus alumnos detecten la respuesta correcta:
Si la pregunta dice "Mobile app", "Lightweight" (ligero) o "JSON" -> La respuesta es REST API.
Si la pregunta menciona "Enterprise integration", "Rigid contract" o "WSDL" -> La respuesta es SOAP API.
Si la pregunta habla de "Loading 500,000 records" o "Large Data Volumes" -> La respuesta es Bulk API.
Si preguntan por la diferencia de WSDLs:
Enterprise = Un solo cliente (fuertemente tipado).
Partner = Muchos clientes (débilmente tipado).
