1. El Reporte de "Cases by Account" (Agrupaciones)
Este reporte suele ser el corazón del reto. La IA busca patrones, por lo que la estructura debe ser impecable.
Agrupación Crítica: Asegúrate de agrupar las filas por el campo Account Name. Si el reto pide una segunda agrupación (por ejemplo, por Status o Priority), hazlo en ese orden exacto.
Filtros de Tiempo: Un error común es dejar el filtro de fecha en "Current FQ". Cambia siempre a "All Time" a menos que las instrucciones digan lo contrario, para que el reporte no aparezca vacío.
2. Columnas y "Cleanliness"
Menos es más: Elimina todas las columnas que el reporte trae por defecto y deja únicamente las que pide el manual. Si Agentforce recibe demasiada información irrelevante, el "grounding" se ensucia.
Nombres de Reportes: Guarda el reporte en la carpeta que creaste en el Reto 1 (o en la carpeta que indique el reto) con el nombre exacto. Salesforce busca el Unique Name (API Name).
3. El uso de "Summary Formulas" (Si aplica)
A veces este reto pide calcular porcentajes o ratios.
Validación de Fórmulas: Si tienes que crear una fórmula de resumen, asegúrate de seleccionar el nivel de visualización correcto (normalmente All summary levels).
Lógica: Revisa si la fórmula pide RowCount o la suma de un campo específico.
4. Checklist para que el Reto Pase (Tips de Validación):
Carpetas (Folders): Verifica que el reporte esté guardado en una carpeta Pública o en la carpeta específica solicitada. Si el validador no tiene acceso a la carpeta, marcará error aunque el reporte esté bien hecho.
Filtros Estándar: Asegúrate de que el filtro "Show Me" esté configurado en "All Cases" (o All Accounts) y no en "My Cases", para que el validador vea todos los registros de prueba de la Org.
Gráficos (Charts): Si el reto pide añadir un gráfico al reporte, asegúrate de elegir el tipo correcto (Bar, Donut, etc.) y de que el título del gráfico coincida si se solicita uno específico.
