# 🚀 Guía de Rol: Release Manager
**Lema**: *"Despliegues aburridos son buenos despliegues."*

---

## 🎯 Tu Misión en Lumina Tech
Eres el último eslabón. Tu territorio son las columnas **7. SF Producción** y **8. Terminado**.

---

## 👣 Tu Ciclo en Trello (Workflow)

### Paso 1: Preparar Deploy (Columna 7)
*   Acumulas tarjetas en **7. SF Producción** que ya fueron aprobadas por el TL.
*   *Acción*: Creas un Change Set de salida o preparas el script de deployment.

### Paso 2: Ejecutar y Cerrar (Columna 8)
*   Despliegas a Producción.
*   Validas que funcione (Smoke Test).
*   Mueves las tarjetas a **8. Terminado**.

> **Mantra**: Nada entra a la columna 8 si no está vivo y funcionando para el usuario final.
